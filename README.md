# Cue2Rule — Project Page

Anonymous project page for double-blind submission. Hosted via GitHub Pages.

Template adapted from [Nerfies](https://github.com/nerfies/nerfies.github.io).

## Anonymity checklist

- [ ] No author names anywhere (including git commit history)
- [ ] No institution affiliations
- [ ] No links to personal/lab pages
- [ ] No identifying screenshots, demo URLs, or dataset names
- [ ] BibTeX uses `Anonymous` as author
